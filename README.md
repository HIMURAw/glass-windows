# Glass Windows

GNOME Shell 50 extension: windows with 45° cut corners and a thin lavender frame (the same shape as Dynamic Island and Glass Dock), plus Windows 11-style snapping.

- **Snap layouts:** `Super+Z`, or drag a window to the top edge and drop it on a zone.
- **Snap assist:** after snapping, pick a window for the empty zone.
- **Super+arrows:** halves and quarters (left → up = top-left quarter), up maximizes, down restores/minimizes.

Install: `./install.sh`, then log out and back in.
